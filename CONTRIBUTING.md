# Contributing

Thanks for helping improve TaskMaster.

## Before opening a pull request

1. Create a branch for your change.
2. Keep changes focused and describe the user-visible behavior in the pull request.
3. Do not commit `.env`, account records, uploaded files, backups, or real user data.
4. Update the relevant document under `docs/` when changing workflows, stored fields, or API behavior.
5. Run the app locally with `npm install` and `npm run dev`, then describe the checks you performed.

## Reporting security issues

Do not include credentials, personal data, or working exploit details in a public issue. Contact the project maintainers privately if a private reporting channel is available.
